# 📖 Vergê

Site responsivo criado com HTML, CSS e Bootstrap como prática de criação de páginas, navegação entre arquivos HTML e uso de componentes do Bootstrap.

## Sobre o projeto

O tema escolhido foi **livros e leitura**. O site conta com três páginas conectadas por uma Navbar fixa, que indica visualmente em qual página o usuário está.

## Páginas

- **Home (`index.html`)** — apresentação do tema, com seção de destaque, texto explicativo e imagem.
- **Tabela (`tabela.html`)** — tabela com uma lista de livros recomendados (título, autor, gênero, ano e nota).
- **Formulário (`formulario.html`)** — formulário para o usuário sugerir um livro, com campo de texto, e-mail, select, rádio, checkbox, textarea e botão de envio.

## Tecnologias utilizadas

- HTML5
- CSS3 (estilos personalizados em `style.css`)
- [Bootstrap 5](https://getbootstrap.com/) (via CDN)
